作成: 2026-11-10 未明（B）。**まだ、スライドは作っていない。**「作って」の指示を待つ。
運営のルール（現地会場）: プレゼン4分（デモ入り）＋質疑1〜1.5分。提出は Google Slides、名前は `プレゼンスライド_VQX`。デモ動画（MP4）を埋め込む。**締切後の差し替えは不可。**

## 1. デザインの方針（マスターの決定）
- **本番のサイトに近づける。** サイトの見た目（太い黒の枠、右下にずらした黒い影、丸いボタン、太い見出し）を、スライドでも使う。
- **「コツ」は、参考画像①「デザインが微妙な時に試すこと18選」の最初の4つの考え方**を取り入れる（マスター確認済み）:
  1. 使うフォントの種類を減らす → **見出し用・本文用の、2種類まで**
  2. フォントの選択を見直す → 見出しは、いちばん太い字。本文は、読みやすい字
  3. 与えたい印象に合わせて、配色を再考する → **サイトの5色だけ**（ポップで、あたたかい印象）
  4. 要素の間隔を調整する → 余白を、そろえる。詰め込まない
- **人のミニキャラを入れる**（サイトの人の絵。`frontend/src/ui/figure.ts`。自作の SVG なので、著作物利用シートの追加は、要らない）。人A=青、人B=ピンク、人C=オレンジ。
- **余白を、埋めすぎない。文章は、短く簡潔に。色味を統一する。**
- 参考画像の「考え方」だけを、取り入れる。**配置や見た目を、そのまま真似しない。**

## 3. 文章の決まり
- 1枚に、伝えることは**1つ**。要素は、**3つまで**。
- 見出しは、**15文字以内**。本文は、1行**約20文字まで**、3行以内。
- 重要度で、文字の大きさに、差をつける（参考画像④）。
- 枠で囲むだけでなく、**見出しと余白で、まとまりを作る**（参考画像④）。
