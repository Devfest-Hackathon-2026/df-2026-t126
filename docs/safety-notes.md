## そのまま貼れる文面
> **安全性への取り組み**
> - **鍵をどこにも置かない**: AI（Vertex AI）は、Google Cloud の認証で呼びます。コード、設定、リポジトリの履歴（過去170コミット）に、鍵やパスワードは、入っていません。
> - **サービスを分け、権限を最小にする**: Cloud Run を3つ（API、AI の処理、期限処理）に分け、AI の処理と期限処理は、外から呼べません。3つとも、専用の実行アカウントで動かし、必要な権限だけを付けています（AI の処理は、データベース、AI、指定のキュー、指定のバケット、配送用アカウントの5つだけ）。
> - **映像を AI に送らない**: 手の位置は、利用者の端末の中で取り出し、AI に渡すのは、数値だけです。
> - **保管は非公開で、期限つき**: 録画と絵は、非公開のバケットに置き、外部への公開を禁止しています。作成から1日で削除の対象になり、削除後の復元もできない設定にしています。
> - **状態を変えられるのは、サーバーだけ**: 画面（利用者）は、読むだけで、ゲームの進行は、サーバーが決めます。ログイン（匿名認証）の確認を通らない操作は、受け付けません。
> - **悪用と費用への備え**: 部屋の参加・作成・ゲーム開始に回数制限を設け、同じ操作の再送でも、二重に数えません。費用は、予算アラートで見張ります。
> - **録画の検証**: アップロードされた録画は、形式、長さ、大きさを、サーバーで確かめてから受け付けます。
